# 测试 E：只在小头里加噪声的整图能量分数模型

分支 `energy-head`，worktree `gpic-wt/energy_head`。代码提交 e929fb6。

## 1. 做了什么

1. 模型：`JiT_T2I` 增加选项 `head_width`。`head_width = 0` 时就是官方点模型。
2. `head_width > 0` 时，`EnergyHead` 替换 `FinalLayer`。骨干每个 x_t 只跑一次。
3. `EnergyHead` 的结构：
   1. 骨干输出的 token 先做 LayerNorm，再用 Linear(640→W) 投影。每个输入只算一次。
   2. 条件向量（时间步嵌入）用 Linear(640→W) 投影。每个输入只算一次。
   3. 然后复制成 M 份。每份有自己的噪声。
   4. 全局噪声：每个样本一个 64 维向量，经 Linear(64→W) 加到条件上。条件经 adaLN 影响所有 token。
   5. 局部噪声：每个 token 一个 64 维向量，经 Linear(64→W) 加到 token 上。
   6. 2 个残差 MLP 块（仓库已有的 `ResBlock`，adaLN 调制），最后是 LayerNorm 和 Linear(W→768)。
4. 宽度 W = 352，M = 2。
5. 初始化：输出层为 0，头里两个块的 adaLN 门为 0，两个噪声层的权重标准差为 0.02。这些和隐式模型的做法一样。
6. 损失：直接用 `ImplicitJiTTrainer`。整张图上的广义能量分数，β = 1，λ = 1，v 空间权重 1/max(1 − t, 0.05)。没有改训练器。
7. 采样：直接用 `ImplicitSampler`。每次调用都抽新的噪声。主数字是 50 次调用，另报 8 次调用。没有改采样器。
8. 没有 CFG。caption 是空 caption。
9. `head_width` 和 `xi_dim` 不能同时打开。代码里有断言。

## 2. FLOPs 表

按手算。每次乘加算 2 FLOP。L = 256 个 token，D = 640，W = 352，ξ 维度 64，patch 维度 768。

| 部分 | 运行次数 | MFLOP |
|---|---|---:|
| 投影 Linear(640→352)，每个 token | 1 | 115.34 |
| 条件投影 Linear(640→352)，每张图 | 1 | 0.45 |
| 局部噪声 Linear(64→352)，每个 token | 2 | 2 × 5.77 = 11.53 |
| 全局噪声 Linear(64→352)，每张图 | 2 | 2 × 0.02 = 0.05 |
| 2 个块：每块 2 个 Linear(352→352) 每个 token，加 adaLN Linear(352→1056) 每张图 | 2 | 2 × 127.62 = 255.24 |
| 输出 Linear(352→768)，每个 token | 2 | 2 × 69.21 = 138.41 |
| 头合计 | | 926.26 |
| 减去被替换的 Linear(640→768) | | −251.66 |
| 每次前向净增加 | | 674.60 |
| 占 34.72 GFLOP 的比例 | | 1.94% |

1. 训练按“前向 × 3”计算，所以训练 FLOPs 也多 1.94%。
2. 现有隐式模型（`xi_block = 6`，M = 2）每张图训练 137.81 GFLOP，点模型 104.15 GFLOP，多 32.3%（`docs/distribution_step.md` 4.1）。
3. 采样时每次调用 M = 1，所以头每次调用只多 (115.34 + 0.45 + 405.23 − 251.66) MFLOP = 269 MFLOP，占 0.78%。
4. `tools/energy/test_energy.py` 第 7 项用 `FlopCounterMode` 测真实模块。d640，文本长度 8：点模型 31.039 GFLOP，能量头 31.714 GFLOP。差值 674.6 MFLOP，和手算完全相等。31.04 低于 34.72，是因为测试的文本长度短，这一项两边相同。
5. 墙钟时间不按 FLOPs 增加。A40 上（vis2，编译后，batch 32）：

| arm | 训练一步 | 一次采样调用 |
|---|---:|---:|
| 点模型 | 74.9 ms | 20.0 ms |
| 能量头 | 82.5 ms（+10%） | 20.1 ms |
| 隐式 | 97.5 ms（+30%） | 20.0 ms |

   多出的时间可能来自 fp32 的损失计算和头里的逐元素运算。这一点没有用 profiler 测。ladder 只按 FLOPs 计分，所以这不影响 ladder 的比较，只影响实际花费。

## 3. 检查（`tools/energy/test_energy.py`，vis2 CPU 上全部通过）

1. 关闭开关：`head_width = 0` 和这次修改前的模型（f429d51 的源码，用 `git show` 载入）在同一种子下参数相同，初始化后的随机数流相同，输出逐位相等。有掩码和无掩码两条路径都测了。输出层改成非零后再比一次，防止比较两张全零的图。
2. 形状：m = 1 时输出 [B, 3, H, W]，m = 2 时输出 [2B, 3, H, W]。新参数都在 `final_layer` 下。
3. 一次骨干：给骨干的每个块和头的每个块挂钩子。一次 m = 2 的前向里，骨干每块只跑 1 次，batch 是 B；头每块跑 1 次，batch 是 2B。同一输入的两个样本不同。同一输入调用两次，结果也不同。
4. 梯度：从官方初始化开始，走 4 步 AdamW 后，骨干（patch 嵌入、第 0 块注意力、最后一块 MLP、文本块）和头（投影、条件、两个噪声层、两个块、输出层）都有非零梯度。两个样本仍然不同。初始化时输出层是 0，所以第 1 步只有输出层有梯度，点模型也一样。
5. 损失公式的手算例子：x = 0，t = 0.5（w = 2），两个样本是常数 1 和 3。to_data = (2 + 6)/2 = 4，between = 4，score = 4 − 4/2 = 2。代码的结果相同。
6. 排斥项的符号：数据点到两个样本的拉力和两个样本的连线正交。梯度下降让两个样本分开。
7. FLOPs：见第 2 节第 4 点。实测增加值和手算相等，并且在 1.94% ± 0.05% 以内。
8. 采样可复现：同一种子两次采样逐位相等，另一个种子结果不同。同一起点噪声采样两次，结果不同，说明每次调用都抽了新噪声。

## 5. 最接近的论文，以及这个设计所在的格子

我读了两篇论文的 LaTeX 源码（arXiv 的 e-print），包括表格和附录。

**De Bortoli 等，Distributional Diffusion Models with Scoring Rules（arXiv 2502.02483）。**

1. 噪声 ξ 和 x_t 形状相同，在通道维度上和 x_t 拼接，从输入层进入。没有头，也没有 adaLN 噪声路径。
2. 所以整个网络每个样本跑一次，每个 x_t 跑 m 次。骨干在样本之间不共享任何计算。
3. 图像上 m = 4。m = 2 的 FID 差 7%。
4. 训练速度（H100，batch 64，每秒步数）：扩散 14.3，m = 2 是 7.85，m = 4 是 4.15，m = 8 是 2.06。
5. 损失：条件广义能量分数，在整个样本上取范数。扫了 λ ∈ {0, 0.1, 0.5, 1}，β 从 0.0001 到 2。没有逐 patch 或特征空间的版本。CIFAR-10 上核分数和能量分数的结果相近。
6. 数据：CIFAR-10 32²，CelebA 64²，LSUN Bedrooms 64²（像素空间），CelebA-HQ 256² 的潜空间。ImageNet 64² 没有得到满意的结果。
7. FID（3 个种子的均值；扩散 / 分布式）：
   - CIFAR-10：NFE 2 时 80.77 / 29.33，NFE 4 时 23.31 / 4.67，NFE 8 时 7.53 / 3.21，NFE 15 时 3.61 / 2.87。
   - CelebA：NFE 2 时 62.85 / 81.79（更差），NFE 10 时 11.67 / 3.60，NFE 15 时 8.51 / 3.45。
   - LSUN：NFE 4 时 41.57 / 69.90（更差），NFE 15 时 6.51 / 5.78。
8. 步数更多（10 到 100）时只有图，没有数字。按正文：λ = 1 在步数多时差于扩散；λ 在 (0, 1) 之间时步数多也保持好；最优 λ 随步数增加而下降。
9. 作者自己列的局限：λ = 1 在多步时变差；噪声只用拼接方式进入，换架构可能明显改善；训练成本随 m 增加。

**Deng 等，Generative Modeling via Drifting（arXiv 2602.04770）。**

1. 一步生成器。损失是 ‖f(ε) − sg(f(ε) + V)‖²，V 是正样本的均值漂移减负样本的均值漂移，核是 exp(−‖x − y‖/τ)。
2. 正样本数的消融（固定 batch）：每类 1 个正样本 FID 20.43，16 个 10.39，32 个 8.97，64 个 8.46。
3. 只保留吸引项时 FID 是 177.14，所以排斥项是必需的。
4. 特征编码器：多尺度 ResNet 特征。没有特征编码器时，作者“无法让方法在 ImageNet 上工作”，即使在 VAE 潜空间里也不行。论文没有给出数字。用 MMD 的形式也没有得到合理的结果。
5. ImageNet 256 FID：潜空间 L/2 是 1.54，像素空间 L/16 是 1.61。像素空间里只用宽 256 的 MAE 特征时 FID 是 32.11。

**这个设计所在的格子。**

| 轴 | De Bortoli 等 | Drifting | 现有隐式模型 | 测试 E |
|---|---|---|---|---|
| 噪声进入处 | 输入层（拼接） | 输入（一步生成器） | 第 6 块之后（后 3 块和输出层） | 只在头里（骨干之后） |
| 每个 x_t 的骨干运行次数 | m 次 | 不适用 | 前 6 块 1 次，后 3 块 m 次 | 1 次 |
| 训练 FLOPs 增加 | m = 2 时约 +100% | 不适用 | +32% | +1.94% |
| 评分空间 | 像素或潜空间，整个样本 | 特征空间，逐位置 | 像素，整张图 | 像素，整张图 |
| 每个条件的正样本数 | 1 | 64 到 128 | 1 | 1 |
| λ | 0 到 1，扫过 | 不适用（漂移场） | 1 | 1 |
| 采样 | 多步，每步新噪声 | 1 步 | 多步，每步新噪声 | 多步，每步新噪声 |

测试 E 的格子是：像素空间、整张图的能量分数、λ = 1、每个 x_t 只有 1 个正样本、噪声只在骨干之后。我没有在这两篇论文里找到这个格子。De Bortoli 等明确说噪声的进入方式可能是瓶颈。Drifting 说像素空间、没有特征编码器时无法工作。但它是无条件或类条件的一步生成，测试 E 学的是 t > 0 时的后验 p(x | x_t, y)，后验更窄，所以不能直接类推。

没有读到的部分：

1. De Bortoli 等在 10 到 100 步的 FID 只有图，源码里没有数据，所以我没有数字。
2. De Bortoli 等没有给参数量，图像上 m 的影响只有“m = 2 差 7%”这一句。
3. Drifting 的 CFG 曲线只有图。
4. 我没有打开 PDF，读的是 LaTeX 源码，表格内容相同。

## 6. 风险

1. 头的表达能力。给定 h 和全局噪声后，各 token 相互独立，因为头里没有 token 之间的运算。所以 patch 之间的相关性只能来自一个 64 维全局向量，经过一个很小的 adaLN。高噪声时后验的主要不确定性是全局结构，可能需要的不只这一个向量。
2. 样本塌缩成均值加小噪声。两个样本共用同一个 h，头可能学成“点预测加一点噪声”。这时测试 E 等于一个带噪声的点模型。JSON 里的 `train_between` 和 `train_to_data` 可以看出这一点。
3. 50 步变差。De Bortoli 等报告 λ = 1 在多步时差于扩散。我们的 toy（`docs/distribution_step.md` 第 3 节）里隐式模型在 50 次调用时也输给点模型。主数字恰好是 50 次调用。
4. 每个 x_t 只有 1 个正样本，并且在像素空间。Drifting 指出的风险在这里仍然存在。
5. 墙钟时间：A40 上训练步慢 10%，不是 2%。
6. 采样器不同：点模型用官方 Euler 加 t_eps（最后剩 0.0144 的噪声），能量头用精确步（最后一步直接返回 x̂）。所以 nn_rms 和 near 有一点差别来自采样器，不完全来自模型。0.0144 远小于 near 的门槛 0.1。
7. 过拟合测试是单向的。N = 256 时，通过只说明代码路径和设计没有明显错误，不能说明在新图像上有帮助。

## 7. 读法（运行前写定）

只看第 24000 步、50 次调用。8 次调用和 1 次调用只报告，不参与判断。

点模型现在有 3 次运行：w1095（covered 0.809，near 0.692，distinct 0.879）、w1113 种子 1（0.883，0.774，0.930），以及这个作业的种子 0。点模型的范围取这 3 次运行的最小值到最大值。`effective_images` 只有这个作业的点模型有。

1. 门槛：energy 的两个种子 covered 都 ≥ 0.7594，才算通过过拟合测试。有一个种子低于门槛，就判为没有通过。
2. 比点模型更好，要同时满足以下 4 条，并且两个种子都满足：
   1. covered 高于点模型 3 次运行的最大值。
   2. near 不低于点模型 3 次运行的最小值。这一条防止用模糊的混合图换覆盖。
   3. distinct 不低于点模型 3 次运行的最大值减 0.02。
   4. effective_images 至少是这个作业点模型的 1.1 倍。
3. 落在点模型范围内：判为打平，不算更好。这时测试 E 多花 1.94% 的 FLOPs，没有收益。
4. 塌缩判据：如果最后的 `train_between` 小于 `train_to_data` 的 0.1，就说明两个样本几乎相同。这时不论其他指标，都读作“头没有学到分布”。原因：样本来自真实后验时，g、g′、x 在给定 x_t 下独立同分布，所以 E‖g − g′‖ = E‖g − x‖，比值是 1。比值远小于 1 说明散布太窄。
5. implicit arm 只作参照，因为它的训练 FLOPs 多 32%，和其他 arm 不是同等算力。它的结果不改变上面的判断。
6. 单个作业，每个 arm 最多 2 个种子。所以“更好”只是继续做的依据，不是结论。
