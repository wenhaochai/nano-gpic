# 自回归：每一步输出下一个 patch 的分布

## 负责人的要求（2026-11-04）

1. “从同一个 x_t 出发多次随机采样是不可能的吧……我就是不想要这个确定性，转而让每一步都变成一个分布，就和LLM每一步输出token的prob一样。”
2. “彻底抛弃确定性的回归采样，转而根据分布随机采样。”
3. “不必要离散分布。”
4. 我指出“一步同时决定 256 个 patch，独立抽样会互相矛盾”后，负责人问：“这确实是一个问题，你觉得改为自回归呢？”我给出计划后，负责人回答：“可以。”

## 设计

p(x | y) = Π p(patch_i | patch_1 … patch_{i−1}, y)，从左到右、从上到下。

1. 主干：d640 的 JiT_T2I，9 + 2 块，加因果 mask。z_i 只看 caption 和 i 之前的 patch。没有噪声水平，时间嵌入看到常数。
2. 一个 patch 的分布：连续分布，一个小 flow（`TokenFlowHead`，宽 1024，3 块，9.87 GFLOP 每张图，占主干的 28.6%，1929 万参数），给定 z_i，建模 patch 的 768 个值。x 预测，v 空间 L2，t_eps 0.05。训练一张图 133.00 GFLOP，点模型 104.15，所以到 C0/8 是 52320 步。
3. 训练：teacher forcing。一次前向得到所有位置的 z，每个位置一个 τ 和噪声。
4. 采样：逐 patch 抽。head 走 32 步 Euler，最后一步落在 x̂ 上。抽出的 patch 裁到 [−1, 1] 再输入。x_T 不用。
5. head 的 τ：logit-normal(−0.8, 1.6)，不是官方的 0.8。`tools/ar/head_modes.py`（8 个模式，768 维，宽 512，1 个训练种子）里抽样离模式更近：rms 0.005 对 0.012。模式份额的总变差是 0.027 对 0.040，采样噪声约 0.016，所以份额没有分辨出来。这个选择只在 toy 上比较过。
6. 第一版没有 KV cache：每个 patch 都跑一次完整主干，生成一张图约 9.1 TFLOP，是 50 步 Euler（1.74 TFLOP）的 5.2 倍。head 训练时仍然每个位置抽一个 τ。

**和 LLM 的一个差别。** LLM 的输出层直接给出每个 token 的概率。flow head 只能抽样，要读出某个 patch 的概率密度需要对 ODE 积分。head 训练时的损失也是对速度的 L2，这是 flow matching 学习分布的方式，不是对 patch 取均值。

## 风险

1. 每个 token 的分布：MAR 用 VAE latent（16 维），我没有搜到在 768 维像素 patch 上这样做的先例。
2. 误差累积：连续 token 没有吸附到词表这一步。过拟合测试里的 `tf_rms` 和 `nn_rms` 用来观察它。
3. 顺序：从左到右时，第一个 patch 要在不知道全局时决定。

4. EMA：算力相同时步数更少，所以 C0/16 处 EMA 里初始权重占 7.3%，基线占 3.5%。这对自回归不利。规则不变，只在 C0/16 失败时报告这个偏差。
5. head 的 τ 嵌入在小 τ 处分辨率低（max_period 10）。如果 N = 256 的模式份额不对，先查这一点。

## 计划

1. CPU 测试和独立评审。
2. 过拟合测试（`jobs/overfit_ar.sh`），规则写在作业头部。
3. 生产路径的冒烟测试（`jobs/smoke_ar.sh`）。
4. d640 训练到 C0/8，算力相同。和点模型比较，两边都有每个提示词自己的随机性：基线 C0/16 是 1529.61，C0/8 是 1083.94（w1098、w1099）。两点都低 5% 以上才算有效。

## 诊断（负责人选择“先诊断，再定设计”，2026-11-04）

负责人问“自回归是怎么做的，MAR？”时，我读了 MAR 论文的表 1（ImageNet 256，MAR-L，Diffusion Loss，不用 CFG 的 FID）：从左到右 + 因果 19.23，随机顺序 + 因果 13.07，随机顺序 + 双向 3.43，MAR 默认 3.50。我们的第一版正好是 Diffusion Loss 几行里最差的组合。我之前只读了摘要，这是我的错。所以诊断加上 MAR 的顺序和注意力。

负责人 2026-11-04 再次强调：我们不用 CFG，默认只有 cond 这个 branch。所以下面只看不用 CFG 的数字。MAR 1.55、GRN 1.81、FractalMAR 6.15 都用了 CFG，不能和我们比较。

我这次读了全文的表，设计落在这些格子里（MAR 论文，MAR-L，400 epoch，不用 CFG 的 FID）：

- 顺序和注意力（表 1）：base 是“从左到右 + 因果”，19.23。random 是“随机 + 双向，每步多个 token”，3.50。
- head（图 4 的表，作者自己训练的 KL-16，16 维 token）：3 块，宽 256 是 3.47，宽 1024 是 2.85。这个 2.85 和上面的 3.50 用的 tokenizer 不同。深度只有一句话“观察类似”，没有表。768 维像素 patch 需要多大的 head，这张表不能回答。
- tokenizer（表 2）：连续的 KL-16 是 3.50，VQ-16 是 7.82。我们的像素 patch **不在表里**。MAR 明确工作在连续 latent 上，不在像素上。所以 3.43 到 19.23 的差距能否搬到像素，是这次诊断要回答的问题。
- 像素上的先例：Fractal Generative Models（Li、Sun、Fan、He，2025），FractalMAR-H（8.48 亿参数）在 ImageNet 256 上 FID 6.15，用了调过的 CFG 和温度，所以不能和上面不用 CFG 的数字并列。它分层递归，最后一级是每个通道 256 类的离散分布，不是一层 768 维的连续 head。这些来自独立评审对论文表 4 和附录 A 的摘录，我自己没有读全文。

和 MAR 的差别。照抄的是遮挡比例、每张图的随机顺序、只在遮挡的 token 上算损失、64 步余弦采样（独立评审逐步核对过）。不同的是：

1. token：像素 patch（768 维），MAR 是 VAE latent。
2. 主干：一个主干跑全部位置，mask token 在全部 9 层里互相注意。MAR 的编码器（16 层）只看已知 token 和 64 个 buffer token，mask token 只进解码器（16 层）。
3. head：flow，x 预测，32 步 Euler，每个 token 1 个 τ，3 块、宽 1024。MAR 是 DDPM，余弦噪声表，学方差，训练 1000 步，采样 100 步，每张图 4 个 t，MAR-L 默认 8 块、宽 1280。
4. 温度：我们是 1.0。MAR 的 README 写明不用 CFG 时用 0.95。温度低可能减少混合，而 covered 的门槛对混合敏感。权重会保存，所以可以事后测。
5. 其他：MAR 有 0.1 的 dropout、head 前学习的位置嵌入和 z 的 LayerNorm，我们没有。优化器设置和 MAR 不同（四臂之间相同）。

所以 random 臂失败只说明这个版本在像素上失败，不说明 MAR 的方法在像素上失败。

`jobs/diagnose_ar.sh`，都是 N = 256，24000 步。门槛不变：covered ≥ 0.7594。

| 臂 | 内容 | 回答什么 |
|---|---|---|
| base | 第一版（从左到右 + 因果），种子 2 | 救援测试：给前 k 个真实 patch，看其余部分能否救回 |
| noise01 | 第一版，前缀加噪声训练和采样，σ = 0.1，种子 2 | 条件增强能否修复 |
| random | MAR 的顺序和注意力，种子 0 | 换顺序能否修复 |
| random_s1 | 同上，种子 1 | 重复 |

读法（运行前写定，含评审 `docs/review_ar_diag_2026-11-04.md` 的数字带）：

1. 救援测试只看 base 和 noise01。random 臂的前缀不是“链的前 k 次抽样”，不读。`late_nearest` ≤ 2 × tf_late 算救回，≥ 0.15 算没救回，中间算不确定。每个 k 有 128 个样本。均值的噪声约 0.011，小于 0.05 的差别不读。主要看 `late_ok`（late_nearest 小于 0.1 的比例），两个 k 之差小于 0.12（约 2 个标准误）不读。
2. k = 1 或 4 就救回：错在最早的几次抽样。k 到 64 或 128 才救回：错在链的前段。k = 192 也救不回：错在几步之内就发散。k ≥ 16 时读 `late_source`：`late_nearest` 低而 `late_source` 高，说明链干净地换到了别的图，这也算救回。
3. `row_rms`、`row_ok`（2048 个样本）只读 base 和 noise01，因为 random 臂不按行生成。从第 0 行就差，混合从第一批抽样开始。第一个 patch 没有上下文，所以这时噪声臂预期无效。前面好、后面差，可能是漂移，也可能是干净地换了图：用读法 2 的 `late_source` 和 `late_nearest` 区分。
4. `first_draw_near`：只有 `first_true_gap` 明显大于 0.1 时才读。很低说明 head 抽出了混合，也回答 head 容量的问题。
5. `late_nearest_k0_head_steps_128`（32 个样本）和同一臂的 nn_late（2048 个样本）比，差 0.06 以上才算 32 步不够。
6. random 的两个种子：covered 均值 ≥ 0.7594 才算修复。noise01：单臂 ≥ 0.7594 才算修复，并且要换种子重跑。任何一个通过，都要重跑 N = 32。nn_late 降到 0.12 以下而 covered 没到门槛，算方向对、强度不够。random 臂的 tf_late 是 30% 已知时量的，不能和 base 直接比。random 臂的 fm 只平均被遮挡的 token，也不能和 base 比。base 用新种子 2，可以和 w1132 的种子 0、1 一起看。
7. 这些都只用来决定下一个设计，不算自回归的结论。

## 采样设置（无训练，`jobs/eval_saved_ar.sh`）

用 w1133 保存的 MAR 顺序权重（种子 0），测 64 和 256 步（MAR 表 1：每步 1 个 token 是 3.43，默认是 3.50）、起始噪声缩放 1 和 0.85。起始噪声缩放不是 MAR 的温度：MAR 缩放每个反向步的噪声，起始噪声不缩放（它不用 CFG 时取 0.95）。我们的 head 是确定的 ODE，没有这样的噪声，所以 0.85 预期主要缩小峰内的散布，对混合作用小。

指标说明。`best_share` 是样本的 256 个 patch 里，和某一张训练图距离小于 0.2 的最大比例。`near_robust` 是 best_share ≥ 0.9 的样本比例。评审用合成样本验证过：两张图的拼贴通不过（最大比例约 0.5）。

读法（运行前写定）：

1. 同口径检查：`s64_t1.0` 就是 w1133 random 臂的设置，只换了随机种子。它的 covered 和 near 与 0.539、0.312 的差应小于约 0.03。否则评估口径不同，不读其他臂。
2. `near_robust` 比 near 高 0.2 以上，而且 `stray` 小于 0.1：散落 patch 的假设成立。
3. 任何设置下原定义的 covered ≥ 0.7594：问题在采样器，权重不用改。这仍是单种子，通过后要在种子 1 的权重上重复。covered 比 `s64_t1.0` 高不到 0.05 不读。
4. 否则，下一个设计要改训练或主干，比如让早期的 token 可以被重新决定。
5. 点模型没有保存权重，所以没有 robust 指标可比。robust 指标只用来解释，不用来判定通过。

## 重新抽样（负责人选择，2026-11-04，`jobs/refine_ar.sh`，无训练）

用 w1133 保存的两份 MAR 顺序权重，每份两个采样种子。所有臂从同一批样本出发，所以是配对比较。

| 臂 | 做法 |
|---|---|
| base | 原样 |
| first16 | 最早抽的 16 个 token，给定其余 240 个，一步重新抽 |
| first64 | 同上，64 个 |
| sweep8 | 把全部 token 随机分成 8 组，每组 32 个，依次给定其余 token 重新抽 |

模型训练时已知 token 最多 30%，这里已知 75% 到 94%（first64 75%，sweep8 87.5%，first16 93.75%）。模型没有在这个范围训练过。原来的采样在后段也要回答这个范围的问题：64 步时，有 10 步已知至少 192 个，最后一步已知 250 个、抽 6 个。但 first64 一步抽 64 个，原来的采样在已知 75% 时不会这样做。MAR 也是训练遮挡至少 70%，采样一直到 0。

读法（运行前写定）：

1. 同口径检查：权重种子 0 的 base，两个采样种子的均值，covered 和 near 与 w1134 的 0.523、0.324 相差应小于 0.03。否则不读其他臂。
2. 早期 token：只读 `stray_by_rank_near_robust_only`。别的样本的标记不代表散落（拼贴里第二张图的 patch 也会被标记）。0-15 的比例取 0-7 和 8-15 两格的均值。它是 128-255 的 5 倍以上，才算早期 token 更容易散落。这不等于散落的都是早期 token：16 个 token 只占 256 个的 6.25%，到 5 倍时也只有约 25% 的散落 patch 来自它们。这个份额由 `stray_share_rank_below` 给出。
3. 通过：某一臂在两份权重上（每份取两个采样种子的均值）covered 都达到 0.7594。通过后先给负责人完整计划和占位图弹窗，再做真实训练（先冒烟测试，再 d640 到 C0/8）。
4. 噪声：配对差（一臂减 base，同一批样本）和它的 bootstrap 标准误（1000 次，按样本重采样）写在 `paired`。同一份权重上，两个采样种子的差取均值，标准误是两个 SE 的平方和开方再除以 2。差小于 2 倍标准误不读。每个样本的数值存在 `*_per_sample.pt`。
5. 没通过但 covered 的上升超过噪声：报告，由负责人决定，不自动做真实训练。
6. 没通过而且 covered 的变化不超过噪声：这组权重上重新抽样没有用。这不否定在训练里放宽遮挡下限 0.7 的设计，也不否定别的纠正办法。报告，由负责人决定。
7. 某一臂让 covered 或 near_robust 的下降超过噪声：报告。这说明模型在已知比例高时的回答比它自己原来的抽样差。

## 跟随测试（负责人选择“先查抽图偏向”，2026-11-04，`jobs/follow_ar.sh`，无训练）

要分清的问题：抽图偏向和散落 patch 的原因，是主干不跟随很少的已知 token，还是 head 抽出来的不是真实 patch。

做法：给模型一张训练图的 k 个真实 token（k = 0、1、2、4、8、16、32、64、128，位置随机），一步抽其余全部 token，逐个位置和训练图的 patch 比较。每张图每个 k 重复 4 次。阈值 0.2 和 `stray` 相同。

| 指标 | 含义 |
|---|---|
| `follow` | 抽出的 token 落在给定图同位置 patch 的 0.2 之内的比例。k = 0 没有给定图，所以是随机水平 |
| `ideal` | 准确的链式法则下的同一比例：在和 k 个已知 token 都一致的训练图中均匀选一张，再抽 |
| `manifold` | 抽出的 token 落在任何一张训练图同位置 patch 的 0.2 之内的比例 |
| `effective_per_position` | k = 0 时，每个位置各训练图被抽中的有效数量，对位置取均值 |
| `baseline_per_position` | 同一统计，用均匀选图的真实 patch 加同样大小的噪声 |

`tools/ar/test_follow.py` 用答案已知的合成抽样验证这些指标：准确链式法则的 follow 等于 ideal，无视已知 token 的抽样停在随机水平，模糊的 patch 的 manifold 接近 0，全部抽同一张图的有效数量是 1。

读法（运行前写定，每个数取 2 个采样种子的均值，2 份权重分别读）：

1. 检查：k = 128 的 `follow` 应不低于 0.9。w1135 里已知 192 个时散落很少。低于 0.9 就说明这个测量和 w1135 矛盾，先查原因，不读后面。训练时已知最多约 77 个 token，所以 k = 64 接近、k = 128 超出训练范围。低于 0.9 也可能是这个原因。k = 64 的值一起报告。
2. head：k = 0 的 `manifold` 不低于 0.8，说明最早的抽样是真实 patch，head 不是主因。低于 0.5，说明 head 抽不准，是主因之一。中间的值只报告。
3. 主干：看 k = 4、8、16 的 `follow / ideal`。在这 256 张图上，这三个 k 的 ideal 不低于 0.995（评审算出），所以实际上就是读 follow。k = 1、2 的 ideal 是 0.630、0.919，是宽松的下界：准确记住 256 张图的模型给 1 个真实 token 时也只有这张图一个候选，这个容差把相近的 patch 算成同一个，所以这两个 k 不读。三个都不低于 0.8，说明给真实 token 时模型会跟随，原因不是“不跟随”，而在抽出来的 token 和真实 token 的差别上。三个都低于 0.5，说明模型不跟随很少的已知 token，是主因之一。其他情况报告 `follow / ideal` 首次到 0.8 的 k。
4. 第一次抽样的偏向：用只计真实 patch（0.2 之内）的计数，`effective_per_position_hit / baseline_per_position_hit` 低于 0.7，说明第一次抽样已经偏向。不低于 0.9，说明单个位置上不偏向。中间的值只报告。只有读法 2 不低于 0.5 时才读这一条，因为真实 patch 太少时这个计数没有意义。
5. 偏向的来源：k = 0 各图的总次数（只计真实 patch），和 w1135 同一权重同一采样种子的最终 `who` 次数，算秩相关（处理并列）。`who` 算两份：全部样本一份，best_share 不低于 0.9 的样本一份，读后一份。作为上限，两个采样种子之间是 0.84、0.89。不低于 0.5，说明最终偏向和第一次抽样的偏向相同。不高于 0.2，说明最终偏向在后面的步骤形成。中间的值只报告。这个检验不能区分第 1 次抽样和第 2 到 16 次抽样，也不能区分“第一次抽样偏向”和“后面的步骤放大了同样的偏好”。
6. 这些读法决定第 2 步（48000 步）的另外 2 臂。提交第 2 步之前，我把读到的结果和这 2 臂报告给负责人。

## 数学工具（负责人 2026-11-04：「我们要实现的生成一个分布的事情 在数学上面没有对应的工具吗？」）

Argon 的独立回答在 `docs/argon_math_tools_2026-11-04.md`，它只凭记忆，没有联网。我核对后的结论：

1. 对象：Markov 核。一步的输出就是一个分布。随机局部化把扩散写成一串后验 μ_t，漂移是后验均值（Montanari 2023，arXiv 2305.10690，式 1.17、1.18）。
2. 损失：严格合适评分规则。交叉熵是其中一个。能量分数不需要密度。L2 只确定均值。
3. 表示：连续高维没有 softmax。「神经网络是函数的万能拟合器，但不是概率密度的万能拟合器」（kexue.fm/archives/9984）。
4. 生成元定理（Generator Matching，arXiv 2410.20587，定理 1）：正则条件下，生成元只有三项：流、扩散、跳跃。所以速度之外只能加扩散或跳跃。跳跃项 Q_t(dy; x) 是每步的一个分布。这是我之前漏掉的工具，Argon 提到后我才读。
5. 该文表 2，无引导，无条件生成，FID：

   | 方法 | CIFAR-10 | ImageNet |
   |---|---:|---:|
   | 速度（Euler） | 2.94 | 4.58 |
   | 跳跃（Euler） | 4.23 | 7.66 |
   | 跳跃 + 速度叠加（Euler） | 2.49 | 3.47 |

   这是我见过的第一张无引导的表，其中分布输出在叠加后胜过速度。我没有读到附录 F 和实验细节（WebFetch 取不到），所以不知道步数、分辨率、一个还是两个网络、跳跃怎么参数化。这是充分训练的结果，不是低算力。

6. 联合问题：Gat 等（arXiv 2407.15595）在 CIFAR-10 上把每个通道当 256 类，每个 token 独立更新，文中说这样“asymptotically”采样正确，推导的误差是 o(h)。结果是 1024 NFE 时 FID 3.63。所以“一步要决定 256 个 patch”只在大步长时成立。
7. 我们的自回归是这个框架的特例：Multiflow（Campbell 等，arXiv 2402.04997）的遮挡状态过程里，token 以概率 t 是真值，否则遮挡，揭开速率 1/(1−t)，模型对每个 token 输出一个分布。η = 0 时揭开的 token 不再改变（只有 M 到真值的速率）。命题 3.3：R^η = R* + η R^DB 对任何 η ≥ 0 都生成同样的条件流。该文在 text8 上选 η = 15，η = 0 时和 D3PM 差不多。
8. 原文附录 F.1.1 给出遮挡状态下的显式形式（我后来读到了）：R^DB(x₁→M) = η，R^DB(M→x₁) = η t/(1−t)。所以 η > 0 时，已揭开的 token 以速率 η 变回遮挡。我之前自己推的 η(1−t)、ηt 也满足细致平衡，但不是原文的取法，下面按原文。first64 是这个过程的粗糙版本，这是我的推断。
9. 跳跃模型在图像上的形式（该文附录 F）：每个像素通道输出一个跳跃强度 λ 和一个 softmax（固定的 b 个 bin，范围 [−1, 1]），U-Net 输出 b + 1 个通道。每步每个维度独立决定是否跳，跳就从 softmax 抽新值。损失是无穷小 KL。这和“LLM 每一步输出 token 的 prob”形式完全相同。跳跃和速度在同一个网络里训练（第 9 节）。

Argon 回答里我不采纳的部分：

1. 它建议的能量分数按 patch 求和。这样只确定每个 patch 的边缘分布，“不会后验坍缩”的定理对联合分布不成立。我的玩具实验里逐 token 版本明显更差（manifold：0.2042 对 0.0129）。
2. “误差的 90% 以上来自主干”没有来源。
3. “自回归一定帮倒忙”没有数据，真实训练还没有跑。理由（欠拟合时 head 占用算力）值得测。
4. “前 16 个 patch 矛盾导致整张图作废”和 w1135 不符：84% 到 90% 的样本仍是一张图，约 3% 的 patch 不对。
5. “模式偏置连乘放大”是假设，它写成了结论。w1136 只说明最终偏向不是第一次抽样偏向的直接延续。

## 测试 A：扫 η（负责人 2026-11-04：「你都做一下测试吧」，`jobs/eta_ar.sh`，无训练）

用 w1133 的两份 MAR 顺序权重，`sample_eta`，η = 0、1、2、5、10、20，每个设置 2048 个样本，64 次主干调用。另加一臂 η = 20、256 次主干调用，用来分开 η 和步长（评审指出的）。token 变回遮挡的概率是 η × 这一步已揭开比例的增量。指标和 w1135 相同，另加有效图数（各训练图样本数的熵的指数）。

这和 w1133 的训练范围不同：η 大时，模型要在已知比例高的情况下回答更多次。w1136 里 k = 128 时 follow 约 1.0，所以这里不算陌生。

读法（运行前写定）：

1. 同口径检查：η = 0 的 covered 和 near 与 w1135 的 base（0.549、0.317 和 0.555、0.355）相差应小于 0.03。否则不读其他臂。
2. 通过：某个 η 在两份权重上 covered 都达到 0.7594，而且同一个 η 在同一份权重上 near 不比 η = 0 低 0.03 以上。
3. 抽图偏向：某个 η 在两份权重上，有效图数都比 η = 0 高 20% 以上，distinct 都高 0.05 以上，而且 near 和 covered 都不比 η = 0 低 0.03 以上，才算 η 减小了偏向。指标互相矛盾时只报告这个权衡。否则采样解决不了抽图偏向。
4. 和 first64 比：first64 的 covered 是 0.732、0.762，near 是 0.855、0.890。这里每个设置只有一个采样种子，每份权重的差要超过 0.03 才读。
5. 如果 η 大时 covered 或 near 下降超过 0.03，报告这一点。η ≥ 10 时每步最大的变回概率不低于 0.25（最后一步 Δt 约 0.0245），下降可能来自步长，不算 η 的反证。这时看 η = 20、256 次调用这一臂（每步最大概率约 0.12）。

## 测试 B：加长训练（`jobs/long_ar.sh`）

依据 w1136：模型要 4 到 8 个真实 token 才锁定一张图，训练里已知 8 个以内的 batch 只占 14.5%（算入 ceil）；最早的抽样有 33% 到 48% 不是真实 patch。

4 臂，都是 256 张训练图、MAR 顺序、48000 步：

| 臂 | 改动 | 针对 |
|---|---|---|
| long_s0 | 种子 0，和 w1133 的 random 相同 | 训练长度 |
| long_s1 | 种子 1，和 w1133 的 random_s1 相同 | 训练长度 |
| long_head6 | 种子 0，head 6 层（MAR-B 的深度，宽度仍是 1024） | 最早的抽样不准 |
| long_few | 种子 0，一半的 batch 已知 0 到 16 个 token（均匀） | 锁定前的一段 |

MAR 的默认训练命令是 3 层 × 1024，MAR-B、L、H 的预训练模型是 6 × 1024、8 × 1280、12 × 1536（README）。long_head6 在这张表里。

每臂训练完做两件事：重新抽样（first16、first64、sweep8，同 w1135），跟随测试（同 w1136）。

读法（运行前写定）：

1. 门槛：long_s0 和 long_s1 的 first64 covered 都不低于 0.7594，算过门槛。原样的 covered 一起报告。
2. 抽图偏向是不是训练不够：long_s0、long_s1 的有效图数比 w1135 的 base（均值约 115、112）都高 20% 以上，distinct 都高 0.05 以上，才算是。
3. long_head6 和 long_few 只和 long_s0 比（同一种子）。k = 0 的 manifold 或 k = 2、4 的 follow 比 long_s0 高 0.1 以上，才算这个改动有效。distinct 和有效图数的读法同第 2 条。这是单种子，只用来决定下一步。
4. 这些臂的结果都不算真实数据上的结论。

## 测试 C：真实训练（`jobs/run_ar.sh`、`jobs/run_point_nodrop.sh`）

d640，同样的训练 FLOPs，没有 caption dropout（负责人 2026-11-04），每个提示一个噪声，EMA，50K 张。

1. 自回归：MAR 顺序，head 3 × 1024，到 C0/8（52320 步）。评测 C0/16 和 C0/8，原样和 first64 两种采样。η 的最好值由测试 A 决定，之后在同一权重上加测。
2. 对照：点模型，同样的数据顺序和裁剪，没有 caption dropout，到 C0/8（66816 步），每个提示一个噪声。这也测出 dropout 本身的影响：对比 w1053 的 1529.61、1083.94。

读法（运行前写定）：

1. 主规则：自回归的 FD 在 C0/16 和 C0/8 都比对照低 5% 以上，算胜出。每个算力点取原样和 first64 里事先定的一种：first64。原样的数字一起报告。

4. recall 和 coverage 一起报告，因为基线缺的是覆盖。
