## 发现（按严重程度）

1. **robust_rms 用中位数，看不见占一半以下的拼贴。** `tools/ar/eval_saved_ar.py:59-60`。
   - 失败：我用真实训练图做了合成样本（`tmp/review_ar_saved/chk.py`）。图 A 的 128 个 patch 换成图 B 的同位置 patch，robust_rms 是 0.000，near_robust 算通过。换 116 个 patch 也是 0.000。所以 near_robust 和 covered_robust 会把“两张图的拼贴”算成“一张图”。诊断里的机制假设（早期 token 来自不同的图）恰好会产生拼贴。
   - 保护：采样设置的读法 1 还要求 stray 均值 < 0.1。拼贴样本的 stray 约 0.45-0.5，会抬高均值，所以读法 1 偏保守，结论不会被拼贴翻转。但 robust_rms、covered_robust 本身会被拼贴抬高。
   - 修法（同样的计算量）：每个样本取匹配 patch 最多的图：`share = (per < 0.2).float().mean(-1)`，`best_share, at = share.max(1)`；robust 近邻定义为 `best_share ≥ 0.9`（最多 25 个 stray patch），stray = 1 − best_share。或者把中位数换成 90% 分位数：合成测试里 8 个 stray 是 0.000，拼贴 50/50 是 0.722，像素平均是 0.475，三者分得开。
2. **“错误在很少的几步之内就放大”超出了预先写定的读法。** `docs/autoregressive.md` 诊断的结果，第 2 条。
   - 失败：按预先的读法 2，只有 k = 192 也“救不回”（≥ 0.15）才读成“几步之内发散”。k = 192 的 `late_nearest` 是 0.145，在不确定带里（`late_ok` 0.461，128 个样本，标准误约 0.044）。另外，k = 192 还要抽 64 个 patch，不是“很少的几步”。
   - 修法：写成“k = 0 到 128 都没救回，所以错误不只在早期抽样或链的前段。k = 192 在不确定带（0.145，靠近 0.15）：在最后 64 次抽样里，rms 从 tf_late 的 0.033 升到 0.145。”
3. **温度不是 MAR 温度的近似，是另一个算子。** `AR_JiT.py:62` 的注释，`AR_JiT.py:114`，`docs/autoregressive.md` 采样设置第一段。
   - MAR 的 `p_sample` 缩放每个反向步加的噪声（`noise * temperature`），起始噪声 x_T 不缩放。我们的 head 是确定的 Euler ODE，只缩放起始噪声。
   - 在 x 预测、τ 从 0 开始时：第 0 步 q 是纯噪声，最优的 hat 是后验均值，和噪声大小无关。之后每步 q = τ·x + (1 − τ)·0.85·η。所以 0.85 只把路径上的噪声分量缩小 15%。
   - 768 维里，‖η‖ 均值 27.7、标准差 0.71；0.85 倍是 23.6，比均值低 5.9 个标准差。head 看到的输入偏离训练分布，它从范数推断的 τ 和输入的 τ 不一致。
   - 对多峰的后验，ODE 的落点主要由噪声的方向决定，缩放范数多半不改变落到哪一峰，只缩小峰内的散布。所以预期 0.85 对“混合”的作用小。
   - 结果仍有用：读法 2 只问“改采样能否到门槛”，和温度的解释无关。修法：把注释和文档里的“MAR 温度的近似”改成“只缩放 ODE 的起始噪声；不是 MAR 的温度（MAR 缩放每步的噪声，起始噪声不缩放）”。
4. **读法缺一个同口径的检查。** `docs/autoregressive.md` 采样设置。s64_t1.0 这一臂就是 w1133 random 臂的设置，只换了随机种子（7）。修法：加一条，“s64_t1.0 的 covered 和 near 与 0.539、0.312 的差应小于约 0.03（near 的标准误约 0.010）；否则评估不同口径，不读其他臂。”也加一个最小效应：covered 比 s64_t1.0 高不到 0.05 不读。
5. **`first_true_gap` 的理由可以写得更具体。** 诊断的结果第 6 条。结论对。数字：256 张图里，35% 的第一个 patch 在 0.1 之内有别的图的第一个 patch，12.5% 在 0.05 之内。所以 `first_draw_near` 高不能说明抽中了“自己的”图。
