# 每一步输出一个分布的模型：设计笔记

负责人 2026-11-03 提出方向：「我们需要设计一个每一步输出一整个分布而不是一个速度的model」。这份笔记是活文档。到目前为止只用了数值验证和 CPU 玩具实验，没有用 GPU，也没有在图像上测试。

## 1. 已验证的数学

代码：`tools/dist_step/posterior_identity.py`（16 维高斯混合先验）。记 y = x + σε。

1. 一个后验决定后面所有后验：p(x | y_s, σ_s) ∝ p(x | y_t, σ_t) · N(y_s; x, σ_s²) / N(y_t; x, σ_t²)，其中 σ_s < σ_t。数值误差 3.8e-40（权重）、8.9e-16（均值）。
2. ODE 的时间导数是后验的矩：沿 ODE，dD/dσ = (m3 − Cov·r) / σ³，其中 D 是后验均值，r = y − D，e = x − D，m3 = E[e‖e‖²]。与有限差分的相对误差 9.7e-6。
3. 所以一个精确后验给出整条路径，不需要再调用网络：400 个子步到路径终点的误差 4.8e-6，路径长度 8.61。
4. 反过来，速度只依赖后验均值（Variational Flow Matching 的结论）。均值准确、步数够多时，分布的其余部分没有用。
5. 这个玩具里，精确速度场上的 Euler 误差：1 步 0.966，2 步 0.386，5 步 0.056，10 步 0.013，50 步小于 0.001。

## 2. ladder 怎样计分，这一点决定设计

1. C 只算去噪网络的训练 FLOPs。评测固定 50 步 Euler、CFG 1.0。
2. d640 评测 5 万张约 5e4 × 50 × 35 GFLOP = 8.7e16 FLOPs，是 C0 的 0.6%。所以 ladder 不奖励少步数。
3. 由第 1 节第 4、5 点，分布输出在 ladder 上只有两条路得分：
   a. 同样的训练 FLOPs 学得更好。
   b. ladder 增加一个“采样步数”轴。这需要负责人决定。
4. 文献也支持这个判断：GMFlow 在 NFE ≤ 8 时胜过基线，NFE ≥ 32 时 FID 只是“competitive”；Distributional Diffusion 在 λ = 1 时步数多了反而差于基线；Posterior Flow Matching 只输出对角方差，FID 从 25.42 到 22.28，这个 FID 水平很低。没有文献显示在 50 步上有明显胜出。

## 3. 玩具实验

代码：`tools/dist_step/toy_head.py`。所有臂共用同一个骨干（MLP，宽 256，4 块），10000 步，3 个种子（`mix_nll` 1 个种子），只改最后一层和损失。数据是 8 个 token，x_t = t x + (1 − t) ε，t 服从与配方相同的 logit-normal。

头的定义（d 是 token 维度）：

- `point`：x 预测，v 空间 L2，即 JiT 配方。
- `wiener`：每个 token 一个锚点 μ 和一个方差 s²，输出是高斯先验的后验均值 x̂ = μ + (t s² / v)(x_t − t μ)，v = t² s² + (1 − t)²。损失不变。μ、s² 都由骨干给出。这是最简单的“输出一个分布”，也等于一个学习到的跳连。
- `mix_t`：每个 token K = 8 个锚点、logit 和方差，权重由贝叶斯公式算出。损失不变。
- `mix_multi`：同一个头，再在一次骨干前向上计算 4 个更低噪声级的 L2（x_s 取自 x_t 到 x 的桥）。
- `mix_global`：所有 token 的 logit 和似然先相加再 softmax，所以每张样本只有一个模式选择。
- `mix_global_multi`：同时用全局选择和多噪声级损失。
- `tangent`：一个锚点和 4 个方向，协方差 U Uᵀ，没有各向同性部分。
- `mix_nll`：混合后验，负对数似然。这是 GMFlow 的形式，但我没有实现它的 transition loss，所以不算它的公平复现。

数据：

- `coupled`：所有 token 在同一格（棋盘的 8 格），token 2 维。真实联合模式 8 个。
- `manifold`：一个隐角决定所有 token，16 维里的 1 维曲线。
- `embedded`：同一曲线，每个 token 32 维。流形在 token 内部，最接近图像 patch。

能量距离（real 对 real 的 3 种子均值标准差：coupled 0.0005，manifold 0.0005，embedded 0.0013）：

| wiener | 0.0014 | 0.0009 | 0.0025 |
| tangent | 0.0124 | 0.0019 | 0.0016 |
| mix_t | 0.0030 | 0.0016 | 0.0072 |
| mix_multi | 0.0027 | 0.0018 | 0.0035 |

这些结果说明：

1. 50 次调用时，K = 8 没有比 K = 1 更好。在这 3 种数据上，收益来自跳连，不来自多模式。
2. embedded 到第 10000 步时，point 最好或打平（wiener 和 tangent 与它的差在 1.5 个标准差内），mix_t、mix_global 明显更差。这是主要风险。
3. 一次调用要输出完整联合分布，必须同时有全局选择和多噪声级损失。coupled 上只有一个条件时能量距离是 0.17–0.19，token 一致率是 0；两个条件都有时能量距离 0.0077，一致率 0.93。
4. 曲线数据上一次调用只拿到粗结构（manifold 到曲线距离 0.91，真实 0.04），因为 8 个锚点盖不住连续流形。
5. 能量距离单独看不够。coupled 上 point 的格内散布只有真实值的 0.52，但 99% 的 token 在有效格内；wiener 散布 1.06，但只有 80% 的 token 在有效格内。这像 precision 和 recall 的取舍。真实参考训练（40k 步）是 precision 0.92、recall 0.0001，方向上和 point 一致。这只是提示，不是证据。

我曾说 embedded 上混合头变差的原因是“各向同性方差把噪声漏到流形之外”。这个解释被否定了：`wiener` 也是各向同性，却和 `tangent` 打平。原因还没有找到。

### 隐式采样器（负责人 2026-11-03 选择先做这个方向）

代码：`tools/dist_step/toy_implicit.py`。网络 x̂ = g(x_t, t, ξ) 输出后验的一个样本。如果 x̂ 来自真实后验，那么 x_t + dt/(1−t)(x̂ − x_t) 在任何步长下边缘分布都正确，最后一步直接返回 x̂（`test_implicit.py` 第 7 项数值验证）。误差只来自模型。损失是整个样本上的广义能量分数，β = 1，λ = 1（严格合适），权重 1/(1−t)。

所有臂的训练算力相同（等于 point 的 10000 步）：`impl_late_m2` 前 2 块每个 x_t 跑一次，后 2 块每个样本跑一次，每个 x_t 2 个样本，实际 6666 步。3 个种子。能量距离：

| 数据 | 调用次数 | point | impl_late_m2 |
|---|---|---|---|
| coupled | 1 | 1.0873 | 0.0280 |
| coupled | 2 | 0.2470 | 0.0154 |
| coupled | 8 | 0.0263 | 0.0072 |
| coupled | 50 | 0.0363 | 0.0570 |
| manifold | 1 | 1.0335 | 0.0129 |
| manifold | 2 | 0.2423 | 0.0075 |
| manifold | 8 | 0.0010 | 0.0022 |
| manifold | 50 | 0.0041 | 0.0267 |
| embedded | 1 | 3.7002 | 0.0395 |
| embedded | 2 | 0.3834 | 0.0290 |
| embedded | 8 | −0.0022 | 0.0097 |
| embedded | 50 | 0.0012 | 0.0063 |

这些结果说明：

1. 1 次和 2 次调用时，隐式采样器比 point 好得多：2 次调用时能量距离低 13 到 32 倍，1 次调用时低 39 到 94 倍。
2. 50 次调用时它输给 point，最好的调用次数约为 8。ladder 的主榜是 50 步，所以评测时要报整条曲线。负责人已决定：50 步是主榜，另报 FD-步数曲线。
3. point 自己在这三种数据上也是 8 次比 50 次好。所以 50 步变差不只是隐式采样器的问题，可能是低噪声处的模型误差累积。这一点没有验证。
4. 我猜 50 次变差是因为 β = 1 的梯度在低噪声处抖动，于是测了 β = 1.5 和 1.8。这个猜测被否定：β 越高，几乎所有格子都更差（embedded 1 次调用：0.0395、0.0706、0.2446）。所以用 β = 1。
5. 逐 token 的能量分数（`tok`）看不到联合结构，1 次调用明显更差（manifold：0.0129 对 0.2042）。所以范数必须取在整张样本上。
6. ξ 晚进入（后 2 块）和从输入进入相比，同样算力下 1 次调用更好（embedded：0.0395 对 0.1164），50 次调用差不多或更差（manifold：0.0267 对 0.0061）。m = 4 没有明显收益。
7. 损失再加均值的 L2 没有帮助（coupled 1 次调用：0.0280 对 0.1296）。
8. 这仍然只是玩具。Drifting 论文报告没有特征编码器时无法在 ImageNet 上工作，每个条件只有 1 个正样本时 FID 也明显差（20.43 对 8.46）。这是像素空间能量分数在图像上的最大风险。这里每个 x_t 也只有 1 个正样本，但在 t > 0 时后验比无条件分布窄得多，所以不能直接类推。

## 4. 设计候选（从便宜到昂贵）

1. `wiener` 头（K = 1）：每个 token 多输出 1 个数，代码约 10 行，FLOPs 基本不变。它检验“训练效率”这一条路。JiT 论文认为高维时没有跳连更好，所以结果可能相反。
2. 全局选择加多噪声级损失（K = 8）：d640 每次前向多 2.0 GFLOP（35 GFLOP 的 +5.8%）。多噪声级只算头，代价很小。高维时全局权重会接近赢者通吃，可以把 token 分组做折中。它检验“一次调用输出联合分布”。
3. 隐式采样器：x̂ = g(x_t, t, ξ)，用严格合适的评分规则（能量分数）或 drifting 训练。它天然是联合的。代价是训练时每个 x_t 要多个样本，所以噪声只进入最后几层。Drifting（Deng 等，2026）一步在 ImageNet 256 上 FID 1.54（潜空间）和 1.61（像素空间），是这个方向最强的基线。这是负责人选择先做的方向，实现见下一节。

## 4.1 隐式采样器在 JiT-T2I 上的实现（分支 dist-step）

- 模型：`JiT_T2I` 增加 `xi_dim`、`xi_block`。d640 的 9 个主块，前 6 块每个 x_t 跑一次，后 3 块和最后一层每个样本跑一次。ξ 分两路进入：全局噪声向量经 adaLN 影响整张图，每个 token 的噪声向量加到 token 上负责局部细节。`xi_dim = 0` 时就是原模型。
- 损失：`ImplicitJiTTrainer`，整张图的能量分数，v 空间权重，每个 x_t 2 个样本，β = 1。
- 采样：`ImplicitSampler`，上面的精确步，没有 t_eps，最后一步返回 x̂。`num_steps` 就是网络调用次数。
- 算力：每张图 137.81 GFLOP（点模型 104.15），所以 C0/4 对应 100992 步（点模型 133600 步）。
- 评测：与 ladder 相同（5 万张，EMA，CFG 1.0，官方噪声），调用次数 50（主榜）、16、8、4、2、1。基线是 ladder 的 d640 在 C0/4 的点，用 50 步。

比较时要说明的事（`docs/review_implicit_2026-11-03.md`）：

1. 点模型的 C0/4 是一个中间检查点，隐式采样器的 C0/4 是它的最后一个检查点。学习率在预热后恒定，所以两者的学习率相同。
2. EMA 半衰期 6931 步相同。隐式采样器的步数少（100992 对 133600），所以 EMA 滞后的比例略大，这对隐式采样器不利。
3. 同样的 FLOPs 下，隐式采样器看到的图像少 24%（2590 万对 3420 万）。
4. 官方配方里所有 rank 种子相同（`seed_everything: 0`，Lightning 的 `reset_seed`）。所以每步 8 个 rank 的 t、噪声和 CFG dropout 都相同，256 张图只有 32 组不同的 (t, 噪声)。隐式采样器的 ξ 也一样。一个 x_t 的两个 ξ 仍然独立，所以损失没有偏差。这一点两边相同。
5. 采样时每个 prompt 的起始噪声相同（官方的共用噪声），8 个 rank 同一 batch 位置的 ξ 也相同。每张图对它自己的 caption 仍是有效样本。

## 5.1 新的设计方案（负责人 2026-11-04：「你再想想怎么出一个分布 给出一些设计方案」）

### 先看三个事实

1. 真实模型缺的是覆盖。d640 在 C0/8（`w1053`、`w1054`）：precision 0.93，recall 0.0003 到 0.0007，coverage 0.18 到 0.20。FD 1504 里 fd_mu 561，fd_sigma 943，协方差项占 63%。所以样本落在真实流形内，但只覆盖很小一部分。这只是读数，我还没有直接测样本方差和真实方差的比值。
2. 模型精确时，分布在 50 步没有好处。`tools/dist_step/noise_share.py`，16 维高斯混合，精确后验，能量距离：

   | 步数 | 每步抽样 | 均值路径（ODE） | 新抽样占最终方差的比例 | 同一 x_0 落到同一模式的比例 |
   |---|---|---|---|---|
   | 1 | −0.0001 | 2.5583 | 1.00 | 0.16 |
   | 2 | −0.0004 | 0.1936 | 0.99 | 0.18 |
   | 4 | −0.0004 | 0.0236 | 0.81 | 0.40 |
   | 8 | −0.0001 | 0.0080 | 0.58 | 0.59 |
   | 16 | −0.0007 | 0.0043 | 0.46 | 0.67 |
   | 50 | −0.0005 | 0.0003 | 0.25 | 0.82 |
   | 200 | 0.0008 | −0.0007 | 0.13 | 0.90 |
   | 800 | −0.0010 | −0.0005 | 0.08 | 0.94 |

   每步抽样在任何步数下都精确。均值路径到 50 步也精确。所以分布在 16 步以内才有直接收益。在 50 步，分布只有两条路得分：训练时学得更好；模型有误差时纠正过窄的分布。
3. 我原来估计新抽样的影响按 1/N 衰减。这个估计错了。表里 50 到 800 步只按约 N^−0.4 衰减，因为模式之间的边界会放大早期的小噪声。所以在 50 步，新抽样的影响不是零。

### 一个方案要回答的三个问题

1. 随机性放在哪一层：每步新抽；一条路径固定一个；只在训练时用。
2. 训练信号有没有对应关系。显式密度和编码器能告诉网络“这张真实图对应哪个样本”。能量分数不能，它在高维里只靠 1 个正样本。Drifting 报告的风险就在这里。
3. 成本：每个 x_t 跑多少块。下面的 FLOPs 都是 d640 的估计，基准是前向 34.7 GFLOP。输出层 Linear(640→768) 是 0.252 GFLOP，占 0.73%（2026-11-04 审计更正：原文写 0.126 GFLOP、0.36%，那是乘加次数。下表和弹窗里按 0.36% 算的头部成本都要乘 2）。

### 方案

| 方案 | 网络输出 | 训练 | 采样 | 每张图多出的 FLOPs | 主要针对 |
|---|---|---|---|---|---|
| A 路径级隐变量 | x̂ = g(x_t, t, y, z)，z 是全局 code | 小编码器 q(z \| x)，v 空间 L2 + λ·KL，每个 x_t 一次前向 | z ~ N(0, I)，一条路径固定，Euler | 约 +0.5% | 50 步主榜 |
| B 频带 Wiener 头 | 每个 token 一个 μ 和 B 个频带方差 | 闭式后验均值，损失不变 | Euler；也可以闭式采样 | 约 +1% | 50 步主榜，低算力 |
| C 一次前向多噪声级 | 同 B 或混合头 | 同一次前向再算 4 个更低噪声级的 L2 | 同 B，另有免费子步 | 约 +1% 到 +6% | 50 步主榜，少步 |
| D 残差分布头 | 均值 + 速度残差的分布（对角、低秩或每 token 小流） | 均值用原损失；残差用似然，停止梯度 | x̂ = m + (1 − t) r̂，精确步 | 低秩 8 方向 +2.9%；小流约 +5% | 少步曲线 |
| E 粒子头 | 一次前向输出 K 张完整样本 | 整图能量分数 | 每步随机取一个，或一条路径固定一个 | K = 8 时 +2.5% | 少步曲线 |
| F 特征空间评分 | 隐式或粒子 | 在冻结编码器的特征上算能量分数 | 同隐式 | 冻结网络是否计入 C，需要负责人决定 | 解决 Drifting 指出的风险 |
| 现有：隐式（`w1056`） | x̂ = g(x_t, t, y, ξ) | 整图能量分数，每个 x_t 2 个样本 | 每步新抽 | +32% | 少步曲线 |

**方案 A：路径级隐变量。** 这是我的首选。

1. 代码：z 走已有的 `xi_global`（adaLN）路径。编码器是 d = 128 的 2 个小块，加平均池化。
2. 为什么可能赢 50 步：训练时 z 告诉网络 x_t 不知道的那部分，回归目标的方差下降，所以每个梯度的噪声更小。这一点我还没有测。采样时 z 不随步数衰减。
3. 数学：编码器只看 x 时，这是以 z 为条件的 flow。模型精确时，任何步数的边缘分布都正确。
4. 文献：Variational Rectified Flow Matching（Guo、Schwing，arXiv 2502.09616）。ImageNet 256，SiT-XL，无 CFG：400K 步 FID 17.2 → 14.6，800K 步 13.1 → 10.6；CFG 1.5：5.40 → 4.91，3.43 → 3.22。我们评测用 CFG 1.0，正好是收益最大的条件。
5. 文献的三点限制：
   - 它的编码器是半深的 SiT，按 FLOPs 算约多 50%（我的估计），这样收益可能接近零。所以我们必须用小编码器。
   - CIFAR-10 上 50 NFE 没有明确收益：FID 5.29 到 5.49，基线 5.29 到 5.56。收益在 2 到 10 NFE。编码器缩到 6.7% 时，50 NFE 的结果没有变差（5.289）。
   - 它用 250 步 SDE，不是 50 步 Euler。
6. 风险：KL 趋于 0 时退化成点模型，这是安全的失败。λ 太小时，先验采样会落到编码器没有覆盖的区域。

**方案 B：频带 Wiener 头。** 最便宜，和 A 独立。

1. 每个 token 在固定的 DCT 基下有一个高斯先验 N(μ_b, s_b²)，x̂_b = μ_b + (t s_b² / v_b)(x_{t,b} − t μ_b)，v_b = t² s_b² + (1 − t)²。
2. 含义：低噪声时增益接近 1/t，细节不必穿过 256 维瓶颈；高噪声时增益接近 0，等于原来的 x 预测。网络自己学每个 token、每个频带的增益。
3. toy 证据：早期明显好，embedded 第 1000 步 0.76 → 0.34；最终在 embedded 上略差，0.0007 → 0.0025。
4. 风险：JiT 论文认为高维时没有跳连更好。

**方案 C：一次前向多噪声级。** 它给每次前向更多监督。ladder 只算训练 FLOPs，所以这条路直接得分。toy：`mix_multi` 在 50 次调用时 0.0027、0.0018、0.0035，point 是 0.0370、0.0065、0.0007。做完 B 再做。

**方案 D、E。** 这两个方案主要改善少步曲线，不是 50 步主榜。D 用停止梯度，所以均值和点模型的训练相同，风险最小。文献：NPPC（Nehme、Yair、Michaeli，arXiv 2309.15533）一次前向输出后验主成分。E 比隐式便宜（+2.5% 对 +32%），但支撑点有限。

**方案 F。** 只有在 A、B 都不够时再做。如果用 DINOv2，就和 FD-DINOv2 指标重合，结论要降级。可以换别的编码器。

### 修订后的方案 A

1. 编码器：x → u，只看 x。d = 128 的 2 个小块，平均池化，输出 64 维。319 MFLOP，占一次前向的 0.92%（实测）。
2. 码率控制：固定容量的高斯信道。û = √d · u / ‖u‖，z = a û + √(1 − a²) ε，a² = 1 − exp(−2R/d)。没有 KL，没有 λ。不管编码器怎样学，都有 I(x; z) ≤ R（香农界）。只有 R 一个超参数。
3. 主网络：x̂ = g(x_t, t, y, z)。z 加到 adaLN 条件上，所有块都能看到。损失不变（v 空间 L2）。
4. 先验：小 flow p(z | y)，条件是 caption 的池化嵌入。输入 z_τ、τ、c，宽 1024，4 个残差块。19 MFLOP，占一次前向的 0.05%（实测）。训练时停止梯度，不影响主网络。
5. 采样：z ~ p(z | y)，一条路径固定。之后是官方的 50 步 Euler，t_eps 不变，CFG 1.0。

按照“每步一个分布”的说法：网络在每一步给出一族以 z 为下标的条件均值，这一族就是 p(x | x_t) 的表示。采样时只抽一次 z，不是每步抽。toy 的第 3 点支持这样做。

为什么可能赢：

1. 高噪声时，z 告诉网络 x_t 不知道的部分，回归目标的方差下降，所以每个梯度的噪声更小。这一点还没有在图像上测。
2. 低维的全局结构由小 flow 学，它极便宜；主网络的算力都用于条件部分。这是这个设计针对 ladder 算力规则的地方。
3. 真实模型现在的读数是 recall 接近 0，协方差项占 FD 的 63%。z 提供持续的随机性，这可能直接改善覆盖。

## 5.3 官方评测只用一个噪声（2026-11-04 发现）

事实：`GPICJsonlDataset` 的种子是 `idx % num_samples_per_instance`。官方配置的 `num_samples_per_instance` 是 1，所以种子总是 0。50K 个提示词全部从同一个 x_T 出发。我用 CPU 核对过：下标 0、1、49999 的噪声完全相同。这段代码来自官方基线（`0a1db96`），不是我们的改动。我之前的脚本和文档写“官方逐提示词噪声”，这是错的。

为什么重要：

1. 共用一个噪声时，噪声不再随提示词变化。方差总量几乎不变，但协方差的形状变了，特征均值也偏离“对噪声取平均”的均值（5.5 节）。两者都进入 FD。
2. 目前所有 FD 都在这个协议下。数字本身仍然有效，但 recall 接近 0 和协方差项占 63% 可能部分来自它。需要测量。
3. 方案 A 不能从 x_T 取 z0：那样所有提示词的 z0 相同。现在 z0 用 `zlib.crc32(key)` 作种子，每个提示词有自己的 z0。
4. 这使方案 A 在官方噪声下有点模型没有的随机性。所以“方案 A 对点模型”的干净比较要让两边都用逐提示词的 x_T。

测试（`jobs/eval_noise.sh`，只做评测，两个 4-GPU 作业，约 3.7 H100-h）：w1053 的 C0/8 上跑 official（必须在 0.1% 内复现 1503.63）、fixed1、fixed2（另一个共同噪声）、prompt_a、prompt_b（逐提示词噪声），C0/16 上跑 prompt_a。读法（运行前写定）：official、fixed1、fixed2 的差异是“噪声身份”的影响。它们的均值与 prompt_a、prompt_b 的均值之差是“共用一个噪声”的代价。`noise_share.json` 给出特征方差里噪声的份额。

修订后的判断规则（运行前写定）：

1. 两边都用逐提示词 x_T：方案 A 的 FD 在 C0/16 和 C0/8 都比基线低 5% 以上，才算有效。只改 GPU 种子方式的两次运行（w1053、w1054）差 2.1% 和 3.5%，一对运行不能估计噪声。
2. 3 个 R 里最好的 R 通过后，还要用另一个 `seed_everything` 再跑一次，也通过才算数。原因：一对 seed 不足以估计噪声，3 个 R 又增加了偶然通过的机会。
3. 官方 x_T 下的结果也报告，和 w1053 的官方 FD 比较。

按作业头部的读法：enc_near 没有明显高于 near，所以混合的图来自主网络，不是小 flow。enc_match 是样本最近的训练图正好是 z 来源图的比例，不设距离门槛：R = 16 时 1% 到 2%，R = 64 时 12%，随机是 0.4%。所以 z 对画哪张图的影响很弱。这个测试不能分开两种原因：主网络不用 z，或者带噪的 z 已经认不出来源图。一个可能的原因：N = 256 时 t 很小的 x_t 就足以认出是哪张图，所以 z 只在 t 约 0.02 以下有用，而 logit-normal 很少采到那里。这些都还没有测。真实数据的后验在更大的 t 上才收窄，所以结论不一定能推到真实数据。

## 5.7 负责人的定义（2026-11-04，问答页）和下一步

负责人的回答：

1. 分布就是问答页上的那条曲线：每一步输出它，不只输出竖线（均值）。
2. “从同一个 x_t 出发多次随机采样是不可能的吧，因为起点确定他就是确定性采样了，我就是不想要这个确定性，转而让每一步都变成一个分布，就和LLM每一步输出token的prob一样。”
3. “彻底抛弃确定性的回归采样，转而根据分布随机采样。”
4. “不必要离散分布。”
5. 方案 A 暂停。

我的理解：网络每一步输出 x 的完整分布，等价于速度的分布。采样器从中随机抽一个，再走下一步。

**一个数学事实。** 抽 x̃ ~ p(x | x_t, y)，令 ε̂ = (x_t − t x̃)/(1 − t)，走 x_t' = t' x̃ + (1 − t') ε̂。这和用 v = (x̃ − x_t)/(1 − t) 走 Euler 是同一个公式。(x̃, ε̂) 是 p(x, ε | x_t) 的样本，所以 x_t' 的分布严格正确，任意步数都成立，1 步也成立。前提是 x̃ 来自**整张图的联合分布**。表 5.1 的“每步抽样”一列就是这个结果。

**和 LLM 的差别。** LLM 每步只决定一个 token，所以不需要多个位置的联合分布。这里一步要同时决定 256 个 patch。高噪声时，不确定的主要是全局结构，所以每个 patch 独立抽样会互相矛盾。分布必须带 patch 之间的相关性。

**真实模型上的一个提醒。** NLL 学到的方差是后验方差加模型误差的平方。5.5 节测到总误差明显大于散布（t = 0.3 时总误差 0.185，散布 0.132），所以低算力时直接抽样的噪声可能偏大。这可能也是 toy 里 `nll_r4` 抽样发散的原因，还没有验证。

**测试 0（无训练，`jobs/eval_stoch.sh`，约 2 H100-h）。** 把主网络的 x̂ 代入 DDPM 的后验，就是每步一个高斯分布 q(x_t′ | x_t, x̂)。先在 w1053 的权重上测每步随机采样本身有没有用。规则写在作业头部。

负责人接着问（2026-11-04）：“这确实是一个问题，你觉得改为自回归呢？”我的回答和计划在对话里，等负责人确认：链式法则消除 patch 之间的矛盾，风险是 token 分布的表示、连续 token 的误差累积和顺序。

官方采样器的一个性质（`tools/dist_step/test_stoch.py` 里也能看到）：t_eps 截断后，50 步的终点是 x̂ + 0.24 (x_0.94 − x̂)，约等于 0.9856 x + 0.0144 ε。所以样本对比度低 1.44%，还带 0.0144 的噪声。`land` 这一项让最后一步落在 x̂ 上，单独测它。

读法的边界：

1. 这个测试把 x̂ 代入 x，没有 Var(x | x_t) 这一项，所以不是真正的每步分布。它只说明代入式随机采样在这两点没有帮助，不能说明网络输出的真实分布没有用。
2. `land` 比 Euler 高 3.7% 到 3.9%。原因没有隔离：`land` 同时去掉 0.0144 的残余噪声和 1.44% 的对比度损失，还直接用 t = 0.98 处很少训练的 x̂。我在对话里说“少量噪声有帮助”，这个说法没有依据，已撤回。
3. 这次运行没有同一 commit 的 Euler 对照。对比跨了 2bd71b7 和 0f4d274，依靠 bf16 到 fp32 的转换是精确的。
4. 独立审计的提醒：共用张量之间 10% 的差异只在一个模型上测过。如果它随模型变化，ladder 的官方张量 FD 有一个未知大小的误差。在 ladder 各点再做一次逐提示词评测可以给出界限。
