# PixelGen in nano-gpic

The model (JiT-T2I) and the trainer of [PixelGen](https://github.com/Zehong-Ma/PixelGen) (Ma et al., "PixelGen: Pixel Diffusion Beats Latent Diffusion with Perceptual Loss"), as the [GPIC code release](https://github.com/keshik6/gpic) ships them, with the changes of the compute ladder. This folder keeps what the ladder runs: `main.py`, `src/`, the ladder's configs in `configs_h100/` and the GenEval prompt lists the configs name. PixelGen's other configs, evaluation sets and demo are in its repository.
